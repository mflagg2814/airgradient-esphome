# airgradient-esphome

ESPHome integration for the legacy DIY Basic v2 AirGradient sensor

### AI disclosure

AI was used to generate this integration from my very outdated [C++ AirGradient fork](https://github.com/mflagg2814/airgradient). Provided without support.

### Fonts

You will need fonts from [here](https://github.com/olikraus/u8g2/tree/master/tools/font/bdf) for OLED display support. Place in `/config/esphome/fonts/` on Home Assistant.

### Hardware

* Wemos D1 Mini ESP8266
* Wemos OLED display SSD1306
* SHT3x temperature and humidity
* Senseair S8 CO2 sensor
* PMS5003 PM sensor
